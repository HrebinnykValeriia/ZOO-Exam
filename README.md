Консольна програма для керування зоопарком.

Є наступні можливості:
- додавання та видалення тварин;
- додавання та видалення вольєрів;
- перегляд списку тварин;
- перегляд вольєрів;
- пошук тварин за ім'ям;
- підрахунок статистики тварин;
- розрахунок необхідної кількості їжі;
- збереження даних у файл;
- завантаження даних із файлу;
- авторизація одного адміністратора.

Також я прибрала if-else при валідації пароля.
При додаванні тварини спочатку перевіряється чи є взагалі місце у вольєрі з відповідним коментарем у консолі.
При виводі усіх тварин тепер виводиться лише тип тварини та її ім'я. Також інформація зберігається у файл тільки якщо були якісь зміни.
